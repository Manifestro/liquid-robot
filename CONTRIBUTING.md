# Contributing

Use a branch for each change. Describe the behavior changed, validation performed and any physical assumptions. Never commit generated Unity caches, environment folders, credentials, runs or model weights. Keep protocol changes explicit: incompatible action/observation changes require a new protocol version and coordinated tests in both repositories. Record algorithm and simulator changes before launching a new run; do not edit a running experiment in place.

See README for the repository-specific validation commands. Dependency changes belong in a separate reviewed change. Third-party packages retain their upstream licenses. No project redistribution license has been selected yet.
